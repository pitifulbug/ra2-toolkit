# RA2 Toolkit

RA2 Toolkit 是一款面向《红色警戒 2：尤里的复仇》的 Windows 辅助工具。程序提供资源、建造、战斗、地图采集、游戏控制和选中对象操作，并允许为每项功能单独设置全局快捷键。

## 功能概览

| 分类 | 功能 |
| --- | --- |
| 资源 | 无限金钱、无限电力 |
| 建造 | 快速建造、全科技解锁、无限生产、随处建造、自动维修 |
| 自动建造 | 围绕选中建筑自动建造防空炮、爱国者导弹、光棱塔或磁暴线圈 |
| 战斗 | 一击必杀、极高防御、超级武器无冷却、超时空无冷却、全员三级、方阵排列、无限射程、极速转身、侵略模式 |
| 地图与采集 | 地图全开、瘫痪裂缝产生器、自动捡箱、捡箱路线 |
| 游戏 | 基地车旋转、暂停游戏 |
| 对象 | 删除选中单位、将选中单位转为我方阵营 |

## 快速开始

1. 从 [Releases](https://github.com/pitifulbug/ra2-toolkit/releases/latest) 下载最新版本。
2. 启动游戏并进入对局。
3. 运行 `ra2-toolkit.exe`。
4. 在控制面板中勾选需要的功能，或点击右侧的快捷键按钮进行设置。

快捷键默认不预设。点击“快捷键：尚未设定”后按下按键或组合键即可保存；按 `Delete` 或 `Backspace` 可清除当前快捷键，按 `Esc` 可取消设置。快捷键保存在：

```text
%LocalAppData%\RA2 Toolkit\hotkeys.json
```

### 需要选中目标的功能

- 自动建造：先选中一个己方建筑，再按防御建筑对应的快捷键；选中步兵或车辆不会启动自动建造。
- 方阵排列、无限射程和对象操作：先选中需要处理的单位。
- 基地车旋转：先选中己方基地车。
- 自动捡箱：先选中一个或多个己方可移动单位；连续按两次自动捡箱快捷键可停止当前选中单位。

## 联机安全

RA2 Toolkit 主要面向单人游戏和本地测试。检测到多人对局时，程序会禁用并恢复一批会直接改变战局的功能。请遵守服务器规则，不要尝试绕过限制，也不要将本工具用于破坏其他玩家的游戏体验。

## 项目结构

```text
ra2-toolkit/
├─ Core/          游戏进程连接、内存读写、状态循环与命令调度
├─ Features/      按资源、建造、战斗、地图和单位等领域拆分的功能实现
├─ Interop/       Windows 原生 API 声明与进程交互封装
├─ UI/            WinForms 控制面板、快捷键和问题反馈界面
├─ Resources/     程序图标、问题反馈图标和应用清单
├─ Properties/    自包含与框架依赖发布配置
├─ Program.cs     程序入口与单实例控制
└─ ra2-toolkit.csproj
```
